# كرتي — نسخة Flutter (المرحلة 1)

⚠️ **هذي المرحلة الأولى فقط** من مشروع كبير — راجع قسم "الخطة القادمة" بالأسفل.

## وش جاهز بهذي المرحلة

- ثيم متطابق مع ألوان النسخة الحالية (React) بالضبط (`lib/theme/app_theme.dart`)
- الاتصال بنفس قاعدة بيانات Supabase الحالية بدون أي تعديل عليها
- تسجيل الدخول بنفس المنطق بالضبط (رقم جوال + كلمة مرور، نفس دوال RPC:
  `login_guard_check`, `username_from_phone`, `login_guard_record`، نفس البريد
  الاصطناعي `@wificards.local`)
- لوحة تحكم أساسية تجيب نفس بيانات `admin_stats()` من قاعدة البيانات
- شريط تنقل سفلي (الصفحات التانية "قيد البناء" مؤقتاً)

## خطوات التشغيل عندك

هذا المشروع **ملفات Dart فقط** — ما فيه مجلدات `android/` و`ios/` الأصلية،
لأن توليدها يحتاج أداة Flutter CLI نفسها (ما تقدر تُكتب يدوياً بمصداقية).

```bash
# 1) ثبّت Flutter SDK إذا ما عندك: https://docs.flutter.dev/get-started/install

# 2) أنشئ مشروع Flutter فارغ بنفس معرّف الحزمة الحالي
flutter create --org com.mofeed --project-name karti karti_app
cd karti_app

# 3) انسخ محتوى مجلد lib/ من هذا الأرشيف فوق مجلد lib/ الجديد (استبدال كامل)
# 4) انسخ pubspec.yaml من هذا الأرشيف فوق الملف الجديد

# 5) ثبّت الحزم
flutter pub get

# 6) عدّل lib/config.dart وحط قيمة VITE_SUPABASE_PUBLISHABLE_KEY
#    (نفس القيمة الموجودة بملف .env بمشروعك الحالي)

# 7) شغّل على المحاكي أو جهاز حقيقي
flutter run
```

## ربط Firebase (للإشعارات)

1. بما إن معرّف الحزمة نفسه (`com.mofeed.karti`)، تقدر تستخدم **نفس** ملف
   `google-services.json` الموجود عندك أصلاً — حطه بـ:
   ```
   android/app/google-services.json
   ```
2. ثبّت أداة FlutterFire:
   ```bash
   dart pub global activate flutterfire_cli
   flutterfire configure
   ```
